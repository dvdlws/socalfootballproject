# SoCal Football Project — Website

Official website for SoCal Football Project, a free youth soccer nonprofit serving the San Gabriel Valley.

## Stack
Pure HTML/CSS — no framework, no build step. One dependency: badge.png (must stay in the same folder as index.html).

## Deploy to Vercel
1. Push this repo to GitHub
2. Import repo at vercel.com
3. Deploy — zero configuration needed

## Deploy to GitHub Pages
1. Push to GitHub
2. Settings → Pages → Source: main branch / root
3. Site live at username.github.io/repo-name

## Connect Custom Domain (socalfootballproject.com)
1. Buy domain at Namecheap (~$15)
2. In Vercel: Project Settings → Domains → Add socalfootballproject.com
3. In Namecheap: Update DNS records to Vercel nameservers
4. Free SSL certificate automatic
